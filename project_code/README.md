# UpSkill Campus Internship - Project Code

## Project 10: Quality Prediction in a Mining Process
`mining_quality_prediction.py`

Expected dataset: `MiningProcess_Flotation_Plant_Database.csv`

Workflow: data loading, cleaning, timestamp features, lag features, time-based split, regression baselines, MAE/RMSE/R2 evaluation, and output generation.

## Project 6: Remaining Useful Life Prediction for Turbofan Engines
`turbofan_rul_prediction.py`

Expected dataset: `train_FD001.txt` or a compatible C-MAPSS training file.

Workflow: C-MAPSS loading, RUL calculation, engine-wise rolling features, engine-level split, regression baselines, and MAE/RMSE/R2 evaluation.

## Important
Run the scripts on the actual internship datasets before putting numerical results in the final report. Update `DATA_PATH` when your dataset is stored elsewhere.
